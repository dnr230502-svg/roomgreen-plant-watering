# 룸그린 물주기 알림판

## 앱 소개
룸그린 물주기 알림판은 기숙사 방에서 여러 화분을 키우는 학생을 위한 식물 관리 웹앱입니다. 식물마다 다른 물주기 간격을 등록하면 오늘 물을 줘야 하는 식물을 한눈에 확인할 수 있습니다. 물을 준 날짜를 기록하면 다음 물주기 예정일이 자동 계산되고, 예정일이 지나면 며칠 지났는지도 표시됩니다.

주요 기능:
- 식물 이름, 물주기 간격, 마지막 물준 날짜, 식물별 색상 등록
- 오늘 물을 줘야 하는 식물과 지연 일수 표시
- 물주기 기록 및 다음 예정일 자동 계산
- 식물별 캘린더와 물주기 이력 확인
- 잘못 기록했을 때 되돌리기와 이력 삭제
- 새로고침 후에도 데이터가 남도록 localStorage 저장
- 로그인, 개인정보, 외부 서비스 연결 없이 사용

## 만든 과정
1. 기숙사에서 식물마다 물주기 간격이 달라 물을 자주 잊는 문제를 정리했습니다.
2. 식물 등록, 오늘 물주기 표시, 물주기 기록, 다음 예정일 자동 계산을 핵심 기능으로 정했습니다.
3. 사용자가 식물 상태를 쉽게 구분하도록 식물별 색상과 캘린더를 추가했습니다.
4. 물을 잘못 기록할 수 있어 되돌리기 버튼과 물주기 이력 삭제 기능을 추가했습니다.
5. HTML, CSS, JavaScript를 하나의 index.html 파일로 제작했습니다.
6. localStorage를 사용해 등록한 식물과 물준 날짜가 새로고침 뒤에도 유지되도록 구현했습니다.
7. 가짜 식물 데이터로 화면과 기능을 테스트한 뒤 GitHub Pages로 공개했습니다.
